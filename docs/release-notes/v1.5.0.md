# Spectra v1.5.0

音频分析桌面工具（PyQt6 + PyAV + OpenGL）。下载 `Spectra-1.5.0.zip`，解压后运行 `Spectra/Spectra.exe`（Windows，免安装）。

## 播放侧（本次主要新增）

- **真立体声播放** —— 数据源改成 `analyzer.data`（原来是 waveform 的 mono mixdown）；单声道文件复制成设备声道数，不依赖系统 upmix。
- **输出通道选择**（播放按钮旁的展开列表）：系统（默认输出设备）/ WASAPI 共享 / WASAPI 独占，按协议分组，行内写「协议 + 模式 — 设备名」。
- **独占模式**：会静音其他应用；能力只能真开一次流才知道，所以启动时后台探测一次（不在构造里开流），结果按通道缓存。
- **回退不静默**：独占失败自动回退共享，状态栏标「回退」；直通判定 `actual_sr == source_sr`（共享路径必然 SRC，不会被误报直通）。
- **按设备名持久化**（`host_api|设备名|模式`），不是索引 —— 拔插设备索引会重排。换通道时保住播放位置（存秒，按新率折帧）。
- 已知边界：只列有输出能力的设备，不列 MME / DirectSound；WDM-KS 暂未支持。本机的「系统」条实际走 MME，所以对它点独占会报 `-9984` 并回退。

## 分析侧

- **EBU R128 LUFS** 重写：K 权重在原生采样率上设计（旧实现降到 12 kHz，Nyquist 只有 6 kHz，高架整段被削），分块 + cumsum 与整段直算一致（maxdiff 1e-13）。
- **TT DR 与 LRA 分开**：DR = K 加权 300 ms 窗 P95−P10（未门控），LRA 是 3 s 块 + 门控，不再混为一谈。
- **削波检测位深感知**：整数量化用 `1.0 − 2·LSB`（s16 → 0.99994），旧写死的 0.999 在 16 bit 下误报 160 次。
- **相位重分配频谱图**（Auger-Flandrin）符号与缩放用啁启真值校过。
- **多分辨率 STFT** 三频段统一到最细的公共行网格（4097 行），重叠区逐行 max，不再逐段各自归一。
- **mel 口径统一为 Slaney**：`backend/scales.py` 是 CPU 侧唯一实现，刻线 / cursor / shader 三处同一口径，常量由 `tests/test_scales.py` 钉死。

## UI / 工程

- 目录重构：`src/spectra/{backend, frontend, assets}`（原 `analyzer/` / `ui/`），import 前缀统一 `spectra.`。
- 无边框窗口 + 内联 SVG 图标（HiDPI dpr 栅格化）+ 快捷键（Ctrl+O / Space / Ctrl+S）+ FloatAnim 动画系统（缩放缓动、LUT 交叉淡化、浮层淡入淡出、滑块 hover）。
- 画布/平底纯黑，主按钮金色渐变，cursor label 透明底。
- 测试 152 项（脱机 mock sounddevice，CI 无 DAC 也能跑），ruff 门 `--select=E,F,W`。
